# Sprint-Tempo-Rechner

Offline-Web-App: berechnet Trainings-Sollzeiten aus 60/100/200-m-Bestzeiten (optional 400 m)
über ein physikalisches Geschwindigkeitsmodell (Hill/Keller, Tibshirani 1997).

**App öffnen:** https://rvpsd9p492-alt.github.io/sprint-tempo/

## Auf iPhone/iPad installieren

1. Link oben in **Safari** öffnen.
2. **Teilen → Zum Home-Bildschirm**.
3. Einmal mit Internet starten – danach läuft die App auch ohne Netz.

Daten bleiben auf dem Gerät. Übertragen/Sichern über „Daten sichern & übertragen“ in der App.
